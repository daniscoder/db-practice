## Состав

Папка практики: `Учебная практика/Учебная практика_ГГГГ-ММ-ДД`. Внутри на
каждое задание своя папка со своим README. Папка называется дословно по
заголовку задания из условия, без номера: в ответе преподавателю дается ссылка
на директорию задания, и проверка идет по названию.

| Папка | Что внутри |
|---|---|
| `<название задания>/` | файлы задания и README с ответом |
| `<название задания>/raw/` | исходники как выданы, без правок |
| `<название задания>/screenshots/` | снимки выполнения, если задание требует показать результат |

Файлы внутри папок называются латиницей. Исходники кладем только в `raw/`: этот
путь ловит правило в `.gitattributes` и защищает их от нормализации переводов
строк. Ссылки на папки с пробелами пишутся в угловых скобках:
`[задание](<./Название задания>)`.
