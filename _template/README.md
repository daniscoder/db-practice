## Состав

Папка практики: `Учебная практика/Учебная практика_ГГГГ-ММ-ДД`. Внутри на
каждое задание своя папка `Задание N. <название из условия>` со своим README:
в ответе преподавателю дается ссылка на директорию задания.

| Папка | Что внутри |
|---|---|
| `Задание N. <название>/` | файлы задания и README с ответом |
| `Задание N. <название>/raw/` | исходники как выданы, без правок |
| `Задание N. <название>/screenshots/` | снимки выполнения, если задание требует показать результат |

Файлы внутри папок называются латиницей. Исходники кладем только в `raw/`: этот
путь ловит правило в `.gitattributes` и защищает их от нормализации переводов
строк. Ссылки на папки с пробелами пишутся в угловых скобках:
`[Задание 1](<./Задание 1. Название>)`.
