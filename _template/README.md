# <Название практики>

Дата: ГГГГ-ММ-ДД · СУБД: PostgreSQL

## Состав

Одно задание — одна папка `task-N-<о чём>`, всё нужное по заданию внутри неё.
Имена и число папок бери из условия практики, пример — из практики 2026-09-07:

| Папка и файл | Назначение |
|---|---|
| `task-1-erd/erd.pdf` | ER-диаграмма |
| `task-2-schema/schema.sql` | DDL |
| `task-3-etl/raw/` | исходники как выданы, без правок |
| `task-3-etl/*.csv` | подготовленные данные |
| `task-3-etl/import.sql` | загрузка + проверочные `SELECT COUNT(*)` |
| `task-4-queries/queries.sql` | запросы по заданию |
| `task-N-*/screenshots/` | снимки выполнения, если задание требует показать результат |

Порядок запуска: `schema.sql` → `import.sql` → `queries.sql`, независимо от того,
по каким папкам они разложены. Исходники кладём только в `raw/` — этот путь
ловит правило в `.gitattributes` и защищает их от нормализации переводов строк.
