# Скидки партнеров: бизнес-логика, база и интерфейс

Учебная практика 14.09.2026. Python 3.14, PySide6, PostgreSQL, psycopg 3.

## Задания

| Задание | Папка | Что внутри |
|---|---|---|
| 1. Расчет скидки | [task_1_discount](./task_1_discount) | функция расчета и тесты границ |
| 2. Интеграция с БД | [task_2_database](./task_2_database) | схема, тестовые данные, запросы |
| 3. Интерфейс | [task_3_ui](./task_3_ui) | окно на PySide6, ресурсы, снимок |
| 4. Наполнение и отладка | [task_4_app](./task_4_app) | точка входа, тесты, снимок прогона |

У каждого задания свой README с ответом. Папки заданий названы так, чтобы быть
и директориями заданий, и пакетами Python: задания здесь - этапы одной
программы, и модули ссылаются друг на друга.

## Запуск

Зависимости:

```
pip install -r requirements.txt
```

База разворачивается по [заданию 2](./task_2_database): создать
`partner_discounts`, выполнить `schema.sql`, затем `seed.sql`.

Приложение, из этой папки:

```
$env:PGPASSWORD = "пароль"
python -m task_4_app.main
```

Тесты с замером покрытия:

```
python -m coverage run -m pytest
python -m coverage report
```

Если база недоступна, тесты задания 2 и сквозные пропускаются, остальные идут
как обычно.
