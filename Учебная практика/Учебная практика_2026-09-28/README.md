## Запуск

Зависимости:

```
pip install -r requirements.txt
```

База та же, что в практике 21.09, `partners_crm`, но схема дополнилась
справочниками типов продукции и материалов. Выполнить `schema.sql`, затем
`seed.sql` из папки задания «Разработка интерфейса истории реализации
продукции». `schema.sql` пересоздает таблицы: добавленные руками партнеры
пропадут.

Приложение, из этой папки:

```
$env:PGPASSWORD = "пароль"
python "Разработка интерфейса истории реализации продукции/main.py"
```

Ошибки приложения пишутся в `app.log` в этой же папке.

Тесты с замером покрытия:

```
python -m coverage run -m pytest
python -m coverage report
```

Если база недоступна, тесты с базой пропускаются, остальные идут как обычно.
