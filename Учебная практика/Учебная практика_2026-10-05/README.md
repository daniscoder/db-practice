# CRM партнеров: от сырых выгрузок до приложения

Учебная практика 05.10.2026, обобщающая. Python 3.14, PostgreSQL, psycopg 3,
PySide6. Не продолжение прошлых практик: своя база `partners_final`, данные
из выгрузок заказчика.

У каждого задания свой README с ответом. Задания - части одной программы,
и модули ссылаются друг на друга. Папки с русскими именами и пробелами
пакетами Python быть не могут, поэтому модули соседних заданий подключаются
через пути поиска: это делают `conftest.py`, `main.py` и `etl.py`.

## Запуск

Зависимости:

```
pip install -r requirements.txt
```

База:

1. Создать базу `partners_final`.
2. Выполнить `schema.sql`, затем `reference.sql` из папки задания 1.
3. Загрузить выгрузки, из этой папки:

```
$env:PGPASSWORD = "пароль"
python "Инфраструктура данных и ETL (База данных в 3NF)/etl.py"
```

Приложение:

```
python "Разработка UI, навигации и CRUD-форм/main.py"
```

Ошибки приложения пишутся в `app.log` в этой папке.

Тесты с замером покрытия:

```
python -m coverage run -m pytest
python -m coverage report
```

Тесты с базой работают в откатываемых транзакциях и данные в ней не меняют.
