Учебная практика 14.09.2026. Python 3.14, PySide6, PostgreSQL, psycopg 3.

## Задания

| Задание | Папка | Что внутри |
|---|---|---|
| 1. Расчет скидки | [Задание 1. Расчет скидки](<./Задание 1. Расчет скидки>) | функция расчета и тесты границ |
| 2. Интеграция с БД | [Задание 2. Интеграция с БД](<./Задание 2. Интеграция с БД>) | схема, тестовые данные, запросы |

У каждого задания свой README с ответом. Задания здесь - этапы одной
программы, и модули ссылаются друг на друга. Папки с русскими именами и
пробелами пакетами Python быть не могут, поэтому модули соседних заданий
подключаются через пути поиска: это делают `conftest.py` и `main.py`.

## Запуск

Зависимости:

```
pip install -r requirements.txt
```

База разворачивается по [заданию 2](<./Задание 2. Интеграция с БД>): создать
`partner_discounts`, выполнить `schema.sql`, затем `seed.sql`.

Приложение, из этой папки:

```
$env:PGPASSWORD = "пароль"
python "Задание 4. Наполнение и отладка/main.py"
```

Тесты с замером покрытия:

```
python -m coverage run -m pytest
python -m coverage report
```

Если база недоступна, тесты задания 2 и сквозные пропускаются, остальные идут
как обычно.
