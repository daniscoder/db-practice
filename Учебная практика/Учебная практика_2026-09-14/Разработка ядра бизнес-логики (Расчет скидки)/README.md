# Задание 1. Расчет скидки

| Файл | Назначение |
|---|---|
| `discount.py` | функция `calculate_partner_discount(total_quantity) -> int` |
| `test_discount.py` | тесты пограничных значений |

## Решение

Границы лежат в таблице `DISCOUNT_TIERS` по убыванию: первая, до которой объем
дотянулся, и дает скидку. Так все числа из ТЗ стоят в одном месте, а не
разбросаны по условиям.

| Объем | Скидка |
|---|---|
| меньше 10 000 | 0% |
| от 10 000 до 49 999 | 5% |
| от 50 000 до 299 999 | 10% |
| от 300 000 | 15% |

Два случая сверх ТЗ. `None` означает, что продаж нет совсем (`SUM` по пустому
набору строк дает `NULL`), и считается как нулевой объем: 0%. Отрицательный
объем отклоняется `ValueError`, потому что продажа в минус - это ошибка данных,
а не повод для скидки.

## Тесты

Проверены обе стороны каждой границы: `9999`, `10000`, `49999`, `50000`,
`299999`, `300000`, а также `0`, `1000000`, `None` и `-1`. Покрытие
`discount.py` - 100% по строкам и по ветвлениям, снимок прогона лежит в
[задании 4](<../Наполнение интерфейса, отладка и стресс-тестирование>).

Запуск из папки практики:

```
python -m pytest "Разработка ядра бизнес-логики (Расчет скидки)"
```
