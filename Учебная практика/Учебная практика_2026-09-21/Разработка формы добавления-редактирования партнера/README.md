# Задание 2. Разработка формы добавления/редактирования партнера

| Файл | Назначение |
|---|---|
| `partner_edit_window.py` | `PartnerEditWindow`: карточка партнера |
| `test_partner_edit_window.py` | тесты полей, списка и подсказок |

## Поля

| Поле | Элемент | Примечание |
|---|---|---|
| Наименование * | текстовое поле | обязательное |
| Тип партнера | выпадающий список | только выбор, свой вариант ввести нельзя |
| Рейтинг | текстовое поле | целое число от 0, подсказка в поле |
| Адрес | текстовое поле | |
| ФИО директора | текстовое поле | |
| Телефон | текстовое поле | подсказка `+7 (999) 123-45-67` и всплывающая подсказка |
| Email * | текстовое поле | подсказка `name@company.ru` и всплывающая подсказка, обязательное |

Раскладка собрана `QFormLayout` и `QDialogButtonBox`, без ручных координат.
Кнопки «Сохранить» и «Назад».

## Решения

- **Выпадающий список** заполняется из справочника `partner_types`. Рядом с
  названием в данных пункта лежит `type_id`: в базу уходит он, а не текст. При
  редактировании пункт выбирается по `type_id`, а не по названию.
- **Рейтинг - текстовое поле**, а не счетчик: ТЗ требует проверять ввод
  нецелого и отрицательного числа, а счетчик такого ввести не даст.
- **Телефон** можно вводить в любом написании, со скобками, пробелами и
  дефисами: перед записью он приводится к виду `+7XXXXXXXXXX`. В карточке
  номер показывается группами.
- **Несохраненные изменения** определяются сравнением полей со снимком,
  сделанным при открытии карточки.

Комментарии в коде стоят только там, где логика неочевидна: заполнение
выпадающего списка, передача id партнера между окнами, снимок полей для
отслеживания изменений.
