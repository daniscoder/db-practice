# CRM: реестр и карточка партнера

Учебная практика 21.09.2026. Python 3.14, PySide6, PostgreSQL, psycopg 3.
Продолжение практики 14.09: одностраничный список партнеров стал реестром,
из которого открывается карточка партнера для добавления и изменения.

| Задание | Что внутри |

| [Обработка исключений и интерактивные уведомления (UX-UI)](<./Обработка исключений и интерактивные уведомления (UX-UI)>) | проверка ввода и диалоги |

В двух названиях заданий в условии стоит `/` («добавления/редактирования»,
«UX/UI»). В имени папки этот знак невозможен, git и Windows считают его
разделителем каталогов, поэтому он заменен дефисом.

У каждого задания свой README с ответом. Задания - этапы одной программы, и
модули ссылаются друг на друга. Папки с русскими именами и пробелами пакетами
Python быть не могут, поэтому модули соседних заданий подключаются через пути
поиска: это делают `conftest.py` и `main.py`.

## Запуск

Зависимости:

```
pip install -r requirements.txt
```

База: создать `partners_crm` и выполнить в ней `schema.sql`, затем `seed.sql`
из папки задания «Интеграция формы с БД». База своя, отдельная от практики
14.09: в карточке появились адрес и email, и схема поменялась.

Приложение, из этой папки:

```
$env:PGPASSWORD = "пароль"
python "Проектирование многооконной архитектуры и навигации/main.py"
```

Тесты с замером покрытия:

```
python -m coverage run -m pytest
python -m coverage report
```

Если база недоступна, тесты с базой пропускаются, остальные идут как обычно.
